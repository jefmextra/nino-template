# Nino Application Template

A production-ready starter template for building high-performance systems with [The Nino Programming Language](https://ninosec.me).

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/jefmextra/nino-template.git my-app
   cd my-app
   ```

2. Run in interpreter mode:
   ```bash
   nino run src/main.nino
   ```

3. Compile to native machine executable:
   ```bash
   nino build src/main.nino
   ./src/main.exe
   ```
